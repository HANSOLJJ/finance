## 인프라 백로그

- **Cron 자동 스냅샷** — 서버가 이제 24/7 상주하므로 서버 안 스케줄러(node-cron 등)로 매일 시세 수집 + 사용자별 스냅샷 기록 가능. "앱을 안 여는 날은 이력이 빈다"는 3차 개편의 구조적 한계 해소. 시세 수집 로직(js/fetch.js)의 서버 이식 필요
- **집 공인 IP 변경 감지** — IP가 바뀌면 키움·빗썸 동기화가 조용히 죽는다(증권사 재등록 필요). 서버가 주기적으로 외부 IP를 확인해 바뀌면 앱 배너/알림
- **트레이딩 봇 1단계** — 조건 감시 + 알림 상주 프로세스 (자동주문은 알림 단계 검증 후. 사용자 결정, docs/handover.md 2절). pm2 앱으로 추가
- **Mac mini 재부팅 리허설** — pm2·cloudflared 자동 복귀 1회 확인 (자동 로그인 전제, docs/SETUP.md 6절)
- **증권사 동기화 후속** — 코스닥 종목 신규 추가 시 티커 접미사(.KQ) 자동 판별 · KIS 페이지네이션(보유 50건 초과 시) · 동기화 행 뱃지 표시. 퇴직연금(DC)·한투 금현물·은행은 API 미지원/허가제라 수동 유지(변경 없음)
- **enc 히스토리 퍼지** — 공개 repo 히스토리에 남은 구 암호문(portfolio.enc) 커밋 청소 (git filter-repo)
